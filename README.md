# WAR ECONOMY — live-data MVP

Адаптивна статична вебплатформа українською мовою для дослідження макроекономічних наслідків війни.

## Запуск
Відкрийте `index.html` у браузері або розмістіть папку на будь-якому статичному хостингу (GitHub Pages, Netlify, Cloudflare Pages).
Для локального сервера:
`python -m http.server 8000`
і відкрийте `http://localhost:8000`.

## Реально підключено
World Bank Indicators API v2 без API-ключа:
- `NY.GDP.MKTP.CD` — ВВП, поточні долари США
- `NY.GDP.MKTP.KD.ZG` — зростання реального ВВП
- `FP.CPI.TOTL.ZG` — інфляція CPI
- `MS.MIL.XPND.GD.ZS` — військові витрати як частка ВВП

Підтримуються Україна, США, Німеччина, Польща, Велика Британія, Франція, Росія та Канада. Кожна метрика показує рік останнього доступного спостереження. Дані завантажуються з API при відкритті сторінки; кнопка «Оновити» повторює запит. Якщо API недоступне, сайт показує помилку, а не підставляє вигадані цифри.

## Реалізовано
- адаптивна навігація;
- головний огляд і реальні макропоказники;
- профілі 8 країн;
- історичні ряди World Bank;
- порівняння країн за обраним роком та показником;
- експорт завантажених даних у CSV;
- локальний журнал перевірок у браузері;
- посилання на джерела, методологію та зовнішні набори даних.

## Що ще потребує серверної інтеграції
- IMF SDMX: для окремих наборів/інструментів доступ може вимагати облікового запису та налаштування API.
- Kiel Ukraine Support Tracker: наразі відкривається сторінка офіційного набору; автоматичне імпортування XLSX та нормалізація таблиць потребують окремого ETL-процесу.
- SIPRI: набір даних має умови використання; комерційне використання потребує дозволу/ліцензії. На сайті залишено посилання на першоджерело, а не скопійовану базу.
- Офіційні дані Мінфіну та Держстату: потрібні окремі адаптери та правила перевірки.

## Важливі обмеження
Це вже live-data MVP, але ще не повноцінний production-сервіс. Запити до World Bank виконуються з браузера користувача; немає централізованої БД, серверного кешу, облікових записів, моніторингу збоїв і глобальної історії ревізій. Локальний журнал зберігається лише в конкретному браузері. Для публічного масштабування рекомендовано додати серверний шар, планувальник оновлень, збереження снапшотів і тестування.
